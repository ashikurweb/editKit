# @editkit/ui ✨

EditKit UI Components — Modern Toolbar, Floating Menus, Modals, Color Pickers & CSS Theme Engine.

<p align="center">
  <img src="https://raw.githubusercontent.com/ashikurweb/editkit-editor/master/assets/editkit-preview.png" alt="EditKit Editor Preview" width="100%" />
</p>

## 📦 Installation

```bash
npm install @editkit/ui @editkit/core
# or
pnpm add @editkit/ui @editkit/core
```

## 🎨 Styles Import

```ts
import '@editkit/ui/styles';
```

## 🚀 Components Included

- **`createToolbar(editor, config)`** — Full formatting toolbar
- **`BubbleMenu`** — Floating text selection bubble menu
- **`TableFloatingMenu`** — Contextual table actions menu
- **`ImageFloatingMenu`** — Floating image resize bar
- **`ColorPickerPopover`** — 2D HSV color picker
- **`EmojiPicker`** & **`SymbolPicker`**
